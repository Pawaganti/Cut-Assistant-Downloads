# Cut Assistant 1.0.33 安装说明

适用环境：Windows 10/11、DaVinci Resolve Studio 21.1 或更新版本。

## 安装版：Windows 安装向导

1. 双击 `Cut-Assistant-1.0.33-Setup.exe`，按安装向导操作。
2. 可在向导里选择是否创建桌面快捷方式。安装后也可从开始菜单打开 Cut Assistant。
3. 请先启动达芬奇，再用桌面/开始菜单快捷方式打开助手；也可在达芬奇“工作区 → 脚本 → Cut Assistant”打开。

默认安装到“文档\HotCore\CutAssistant”。程序在 `app`，个人设置在 `data`。更新安装不会覆盖 `data` 中的配置。Windows“已安装的应用”里可以卸载程序；卸载保留个人配置，便于以后重新安装。

## 便携版：解压并复制

1. 解压 `Cut-Assistant-1.0.33-Portable.zip`。
2. 将里面的整个 `Fusion` 文件夹复制到 `%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\`，合并同名目录。
3. 从达芬奇“工作区 → 脚本 → Cut Assistant”打开。若脚本菜单尚未更新，请重新打开达芬奇。

便携版不注册 Windows 安装记录，也不创建桌面快捷方式。迁移到另一台电脑时，复制同样的 `Fusion` 文件夹即可。两种方式选择一种，不要同时安装。

## 首次使用

如提示部分功能尚未完成配置，请进入“设置 → 快捷键 → 达芬奇命令”，按页面说明完成配置。自定义快捷按钮与达芬奇命令是两种不同设置。

程序每次打开时读取一次当前项目、时间线及所选片段状态，之后不进行后台轮询。切换片段后如需立即核对高亮和数值，可在主面板空白处右键选择“刷新当前状态”。

`使用手册.pdf` 随程序提供。如手册中的安装方式与此说明不一致，以此说明为准。
