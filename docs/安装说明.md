# Cut Assistant v1.0.32 安装说明

适用环境：Windows、DaVinci Resolve Studio 21.1 或更新版本。

**此版本提供两个 ZIP 包，选择其中一种即可。`Installer.zip` 需要运行安装脚本，不是 Windows 安装向导。**

## 方式一：脚本安装

1. 解压 `Cut-Assistant-1.0.32-Installer.zip`。
2. 打开解压后的文件夹，运行 `安装.cmd`。
3. 在达芬奇的 **工作区 → 脚本 → Cut Assistant** 打开助手。

程序默认安装在“文档\HotCore\CutAssistant\app”，个人设置保存在旁边的 `data` 文件夹。重新运行安装脚本时会保留已有个人设置。

## 方式二：复制使用

1. 解压 `Cut-Assistant-1.0.32-Portable.zip`。
2. 复制整个 `Fusion` 文件夹到以下目录，并合并同名文件夹：

   `%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\`

3. 在达芬奇的 **工作区 → 脚本 → Cut Assistant** 打开助手。如果菜单中暂时没有出现，请重新打开达芬奇。

复制后，程序位于 `Support\Fusion\CutAssistant\app`，脚本入口位于 `Support\Fusion\Scripts\Utility\Cut Assistant.py`。

## 首次使用与状态刷新

若提示“部分功能尚未完成配置”，请打开 **设置 → 快捷键 → 达芬奇命令**，按页面指引完成配置。自定义快捷按钮与达芬奇命令配置是两项不同设置。

助手每次打开时读取一次当前项目、时间线及所选片段状态。此后不在后台持续轮询；如需立即核对数值或高亮，可在主面板空白处右键选择“刷新当前状态”。

程序附带 `使用手册.pdf`。手册中个别旧版自动刷新说明尚未同步，以上述操作为准。
