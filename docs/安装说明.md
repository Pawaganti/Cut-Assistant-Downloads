# Cut Assistant 1.0.32 安装说明

环境：Windows，DaVinci Resolve Studio 21.1 或更新版本。

## 方法一：普通安装

1. 解压 `Cut-Assistant-1.0.32-Installer.zip`。
2. 打开解压后的文件夹，双击 `安装.cmd`。
3. 打开达芬奇项目，在“工作区 → 脚本 → Cut Assistant”启动。

默认程序安装到“文档\HotCore\CutAssistant\app”，个人设置在旁边的 `data`。

## 方法二：直接复制

1. 解压 `Cut-Assistant-1.0.32-Portable.zip`。
2. 复制里面的整个 `Fusion` 文件夹，到以下位置并合并同名目录：

   `%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\`

3. 在达芬奇“工作区 → 脚本 → Cut Assistant”启动。脚本菜单尚未更新时，重新打开达芬奇。

复制后应能看到 `Support\Fusion\CutAssistant\app` 和 `Support\Fusion\Scripts\Utility\Cut Assistant.py`。

## 首次使用

如提示部分功能尚未配置，进入“设置 → 快捷键 → 达芬奇命令”，按页面说明点“开始配置”。自定义快捷按钮与达芬奇命令配置是不同功能。

两包均包含完整 `使用手册.pdf`，可查看功能、手势、预设和迁移说明。换电脑时如需保留自己的布局或键盘方案，在软件里分别导出软件配置和快捷键配置。

两种安装方式选择一种即可。安装包不含个人配置及诊断工程。



助手每次打开时读取一次当前项目、时间线及所选片段状态，更新面板数值与高亮。之后不后台轮询；切换片段后如需立即核对显示，可在主面板空白处右键选择“刷新当前状态”。旧版手册中的自动刷新间隔说明由本说明替代。

场景剪切探测恢复单击、Shift + 单击和右键范围选择。框选多个片段时，按最早入点到最晚出点执行一次达芬奇原生探测；助手不改动轨道锁。支持屏幕边缘吸附与悬浮球。

收起条的可见及鼠标触发区域靠边且较小。窗口直接收起和展开，只对小条轻微淡入，避免透明窗口逐帧缩放造成卡顿与画面破碎。

双击标题栏可切换悬浮球。顶栏锁定按钮可固定窗口位置、尺寸，并在贴边时保持展开；解除锁定后恢复自动收起。设置从主面板空白处右键打开。动态缩放的起止画面交换位于“变换／动态缩放叠加层”按钮的右键菜单。
